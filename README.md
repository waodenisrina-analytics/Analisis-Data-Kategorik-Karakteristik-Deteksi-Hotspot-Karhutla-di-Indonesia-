# Analisis-Data-Kategorik-Karakteristik-Deteksi-Hotspot-Karhutla-di-Indonesia-
Analisis data kategorik pada 3.350 titik hotspot karhutla di Indonesia (11-12 Nov 2026): uji chi-square, regresi logistik biner &amp; multinomial dengan galat baku cluster-robust, serta analisis sensitivitas. R Markdown.
